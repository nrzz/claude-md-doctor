# Roadmap

What could come next. None of it is promised; all of it is open to contributors. Comment on an issue or start a [discussion](https://github.com/nrzz/claude-md-doctor/discussions) before a large change.

- Stemming for near-duplicate rules ("before committing" and "before you commit" are not matched yet).
- Python task runners in `stale-command`: `pdm run`, `hatch run` and `poe` tasks defined in `pyproject.toml`.
- A ready-made GitHub Action that posts the Markdown report on pull requests.
